良かったところ

この構成のいいところ

🔒

外に何も出ない

/v1/images を叩かない。画像は Codespaces のメモリの中だけ。外向きの URL は一切発行されない。

📦

外部サービスゼロ

Supabase も Fly.io も使わない。Codespaces 1 つあれば全部動く。月額コストもかからない。

⚙️

セットアップ 1 コマンド

Codespace を起動するだけ。postCreateCommand が pnpm install + Playwright + build までやってくれる。

⚡

2回目以降は爆速

同じ URL ならプロセス内 LRU キャッシュから即返却。ネットワーク往復ゼロなのでミリ秒で返ってくる。

弱いところ

逆につらいところ

HIGH

Playwright がとにかく不安定

Figma 側の DOM が変わると一気に動かなくなる。Shift+2 みたいなショートカット頼みでもあるので、Figma が更新されるたびに追いかけるハメになる。

MED

Codespace が壊れたら作り直し

Figma ログイン情報も Playwright Chromium も Codespace のディスクにあるので、Codespace を削除したら全部やり直し。再ログインが要る。

MED

Figma のログインが切れると詰む

Chrome プロファイルの認証が切れると手で入り直さないといけない。自動でリフレッシュする仕組みはまだ作ってない。
